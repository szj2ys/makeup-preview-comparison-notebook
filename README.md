# Makeup Preview Comparison Notebook

A small offline notebook for comparing makeup previews made from the same input image. Record the makeup changes you can see, separate them from changes to face shape or lighting, and choose one detail to practice.

The files work in a spreadsheet or text editor. No installation, account, image upload or API connection is needed to use the notebook.

## Start here

1. Read the short workflow in [METHOD.md](METHOD.md).
2. Copy [comparison-worksheet.csv](comparison-worksheet.csv) into a private working folder. It contains column headings and no observations. Open it as UTF-8, comma-separated text; treat the columns as text.
3. Pick one input image and one question, such as whether a shorter eyeliner wing is easier to recreate. Give the input a local identifier, then record one row for each preview.
4. Check face shape, lighting and texture before comparing the makeup. Mark an output that changes these features as needing a retest or as not comparable.
5. Write a few concrete steps for one makeup detail you want to try. Keep the physical practice notes separate from what an AI image appeared to show.

Use [illustrative-example.csv](illustrative-example.csv) to learn the format. **Every example row is fictional.** No images were generated or inspected for it, no person took part, and it is not a test or review of any product.

## Files

| File | Purpose |

| `illustrative-example.csv` | Three fictional rows showing a usable comparison, a changed-face output and an uncontrolled input. |

## What the notebook can tell you

It can help you describe a visible lip, eye or cheek detail and decide whether a comparison is fair enough to inform practice. It records your observations; it does not measure a model's accuracy or rank products.

An AI preview does not show how makeup will wear on skin. It cannot establish a foundation match, the real finish of a product, or how a look will appear under different lighting. A sample portrait also does not show how a look will appear on your own face.

Keep portraits, generated outputs and completed worksheets in your own working folder. The shared template needs only local image identifiers, not names, face images or public photo links.
